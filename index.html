ℹ️ How It Works
A2Launcher uses Eaglercraft to run Minecraft directly in your browser via WebGL + WebSocket.

❶ Click any server → ❷ Eaglercraft loads → ❸ Enter a username → ❹ Click Join → 🎮 Play!

No installation needed. Works on PC, tablet, and phone. Free forever.
