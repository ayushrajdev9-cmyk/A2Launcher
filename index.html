ℹ️ How It Works
A2Launcher uses Eaglercraft to run Minecraft in your browser via WebGL + WebSocket.

1. Click a server → 2. Eaglercraft opens in new tab → 3. Enter username → 4. Click Join → 🎮

Works on PC, tablet & phone. 100% free. By Ayush Rajdev & Anzar Iqbal.
