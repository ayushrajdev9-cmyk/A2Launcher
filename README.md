# A2Launcher - Minecraft Web Client

**Play Minecraft in your browser — no download, no Java, no install!**

Created by **Ayush Rajdev** & **Anzar Iqbal**

## ?? Live Demo
?? **[https://a2launcher.vercel.app](https://a2launcher.vercel.app)**

## ?? Features
- Play Minecraft directly in your browser using Eaglercraft
- One-click join popular servers (Hypixel, CubeCraft, etc.)
- No Java or Minecraft installation required
- Works on PC, tablet, and phone
- 100% free and open source

## ?? Server Browser
Click any server to join instantly:
- Eaglercraft Official
- Eaglercraft Network
- MC Land
- Build The Earth
- ShieldPVP
- Custom server support

## ?? Deployment
This project is deployed on Vercel as a static site.
